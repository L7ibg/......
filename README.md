# دعوة خطوبة تفاعلية - عبدالقادر ونور

هذه صفحة دعوة تفاعلية جاهزة للرفع على GitHub Pages.

## الملفات الموجودة:
1. `index.html`: ملف الصفحة الرئيسي بتصميم أنيق وألوان ذهبية وأبيض.
2. `README.md`: ملف التوضيح.

## طريقة الرفع على GitHub:
1. أنشئ مستودعاً جديداً (Repository) على حسابك في GitHub.
2. ارفع ملف `index.html` مباشرة إلى المستودع.
3. اذهب إلى إعدادات المستودع (Settings) ثم (Pages).
4. من قسم (Build and deployment)، اختر الفرع `main` واضغط حفظ (Save).
5. خلال لحظات سيظهر لك رابط موقع الدعوة التفاعلية الخاص بك!
